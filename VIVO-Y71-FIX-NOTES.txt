OHLI TUNEL v3.2.0 - VIVO Y71 / ANDROID OREO

Perubahan kompatibilitas:
1. minSdk 26 (Android 8.0 Oreo).
2. targetSdk 28 agar lebih konservatif pada Android Oreo.
3. applicationId diganti menjadi com.ohli.tunel agar tidak bentrok saat signature APK berbeda dari versi lama com.rk.tunnel.
4. Foreground service memakai API umum, tidak lagi mendeklarasikan specialUse API 34.
5. Tetap build debug universal dengan ABI arm64-v8a dan armeabi-v7a.

Catatan: sumber belum dibuild pada perangkat Vivo Y71. Jalankan GitHub Actions dan uji APK hasilnya. Ini bukan jaminan instalasi sampai pesan error asli diketahui.
